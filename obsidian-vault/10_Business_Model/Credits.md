## 設計目標

| 目標 | 說明 |
|------|------|
| **彈性付費** | 學生依實際用量付費，低門檻進入 |
| **成本對齊** | AI 推理、影片串流、儲存等邊際成本可追蹤 |
| **行為激勵** | 獎勵良好學習行為 (連續登入、完成單元、助人) |
| **商業彈性** | 可動態調整價格、推出促銷、包裹方案 |
| **透明度** | 學生清楚知道每項功能「價值多少 Credits」 |

## 核心概念

### Credits 定義
> **1 Credit = 平台內統一計價單位**
> 
> 類比：遊戲幣、雲端運算信用點

### 雙幣制架構 (可選)
| 幣別 | 來源 | 用途 | 可轉換 |
|------|------|------|--------|
| **Gold Credits (付費幣)** | 真金白銀購買、訂閱贈送 | 所有付費功能 | 不可轉換為 Silver |
| **Silver Credits (獎勵幣)** | 學習成就、每日登入、邀請好友 | 部分功能、兌換周邊 | 不可轉換為 Gold |

> **決策點**：是否採用雙幣制？單幣制較簡單但彈性較低。

## Credits 消耗項目 (草擬)

### AI 相關 (高頻、高成本)
| 功能 | Credits/次 | 計費邏輯 | 備註 |
|------|------------|----------|------|
| AI 對話 1 輪 (學生問 + AI 答) | 1-2 | 每輪扣除 | 含 Context 建構、RAG、模型推理 |
| AI 完整解答 (關鍵句觸發 TBD-04) | 5-10 | 每次 | 含完整推理步驟生成 |
| 相似題生成 1 組 (3-5 題) | 5-10 | 每次 | 含題目生成、驗證、標籤 |
| AI 學習報告生成 | 10-20 | 每份 | 週報/月報/專項分析 |

### 學習內容 (低頻、沉沒成本)
| 功能 | Credits/次 | 計費邏輯 | 備註 |
|------|------------|----------|------|
| Level 測驗 1 次 | 2-5 | 每次 | 含抽題、評分、分析、Mastery 更新 |
| 初始能力測驗 | 0 (免費) | - | 註冊流程核心、不收費 |
| 補強練習 (AI 生成) | 3-8 | 每組 | 針對弱項 KP |
| 影片離線下載 | 1-2 | 每支 | 頻寬/儲存成本 |

### 進階功能 (增值)
| 功能 | Credits/次 | 計費邏輯 |
|------|------------|----------|
| 詳細學習分析報告 (PDF) | 10 | 每份生成 |
| 家長帳號綁定 | 0 (訂閱含) / 50 | 每綁定一組 |
| 專屬客服優先回應 | 20 | 每次工單 |
| 自訂練習卷 (匯出 PDF) | 5 | 每份 |

## Credits 帳戶管理

### 餘額查詢
```typescript
interface CreditsAccount {
  studentId: string;
  goldBalance: number;      // 付費幣
  silverBalance: number;    // 獎勵幣
  totalEarned: number;      // 歷史總獲得
  totalSpent: number;       // 歷史總消耗
  lastTransactionAt: DateTime;
  
  // 訂閱相關
  subscription?: {
    planId: string;
    monthlyGrant: number;     // 每月贈送 Gold
    nextGrantAt: DateTime;
    autoRenew: boolean;
  };
}
```

### 交易記錄
```typescript
interface CreditsTransaction {
  id: string;
  studentId: string;
  type: "EARN_GOLD" | "EARN_SILVER" | "SPEND_GOLD" | "SPEND_SILVER" | "CONVERT" | "EXPIRE" | "REFUND" | "ADJUST";
  amount: number;           // 正數=收入、負數=支出
  balanceAfter: number;
  source: "PURCHASE" | "SUBSCRIPTION_GRANT" | "DAILY_LOGIN" | "LEVEL_COMPLETE" | "INVITE" | "AI_CHAT" | "LEVEL_TEST" | "SIMILAR_QUESTION" | "ADMIN_ADJUST" | "EXPIRATION";
  referenceId?: string;     // 關聯訂單/活動/功能 ID
  description: string;
  metadata?: Record<string, any>;
  createdAt: DateTime;
}
```

### 過期與保護機制
| 規則 | 參數 | 說明 |
|------|------|------|
| **Gold 過期** | 無期限 / 2 年 | 付費幣原則不超期，或依法規設定 |
| **Silver 過期** | 180 天無活動 | 鼓勵持續使用 |
| **最低保留** | 10 Credits | 避免歸零導致完全無法使用核心功能 |
| **破產保護** | 餘額 < 5 時鎖定付費功能 | 防止負債，引導購買 |

## 定價與匯率

### TWD ↔ Credits 匯率
| 方案 | 匯率 | 設計邏輯 |
|------|------|----------|
| **基準匯率** | 1 Credit = $1 TWD | 直覺好算 |
| **量購優惠** | 1 Credit = $0.75-0.9 TWD | 鼓勵大額儲值 |
| **訂閱折扣** | 含贈送 Credits，實質匯率更低 | 鎖定長期收入 |

### 動態定價 (未來)

- 依時段調整 (尖峰/離峰)
- 依用戶分群調整 (新用戶優惠、高價值用戶維繫)

## 會計與稅務

### 收入確認
| 交易類型 | 收入確認時點 | 會計科目 |
|----------|--------------|----------|
| 單次購買 Credits | 交易完成即時 | 預收收入 → 收入 (隨消耗攤銷) |
| 訂閱月費 | 服務期間按月攤銷 | 預收收入 → 收入 |
| 贈送/獎勵 Credits | 無收入確認 | 行銷費用 / 成本 |

### 稅務合規
- 電子發票自動開立 (購買/訂閱)
- Credits 消耗不開立發票 (已在購買時開立)
- 退費政策：未消耗 Gold 可退費 (扣手續費)，Silver 不可退

## 風險與控制

| 風險 | 控制措施 |
|------|----------|
| **Credits 通膨** (過度贈送導致購買意願下降) | 監控 Gold/Silver 比例、總發放量、平均餘額；設定每月上限 |
| **刷單/作弊獲取** | 設備指紋、行為分析、人工審核、封鎖機制 |
| **儲值後棄用** (斷層) | 定期提醒餘額、推薦用法、休眠喚回 |
| **匯率混淆** | 介面明確顯示「約等值 $X TWD」 |
| **法律風險** (預付卡法、消保法) | 法務審核、保留足夠準備金、明確條款 |

## 實作里程碑

| 階段 | 交付項目 |
|------|----------|
| **Phase 1 (MVP)** | 無 Credits 系統，所有功能免費 |
| **Phase 2 (付費化準備)** | Credits 核心帳戶、交易記錄、基本消耗邏輯 |
| **Phase 3 (商業化上線)** | 購買/訂閱流程、發票、後台管理、數據儀表板 |
| **Phase 4 (優化)** | 動態定價、A/B Test、預測模型、LTV 最大化 |
