## 研究目標

整理教育領域 AI 應用的最新進展、最佳實踐與前沿技術，為平台 AI 教學系統設計提供理論與技術支撐。

## 核心研究主題

### 1. 智慧導師系統 (ITS, Intelligent Tutoring Systems)

#### 經典架構 (四大模組)
```
┌─────────────────┐
│   Domain Model  │  ← 領域知識 (數學概念圖、技能圖、先備關係)
├─────────────────┤
│  Student Model  │  ← 學生畫像 (知識掌握度、錯誤模式、學習風格)
├─────────────────┤
│  Pedagogical    │  ← 教學策略 (何時提示、何時示範、支架遞減)
│    Model        │
├─────────────────┤
│  Interface      │  ← 互動介面 (對話、視覺化、多模態)
└─────────────────┘
```

#### 關鍵技術演進
| 時代 | 技術特徵 | 代表系統 |
|------|----------|----------|
| **第一代 (1970-1990)** | 規則基礎、專家系統、框架/腳本 | SCHOLAR, GUIDON |
| **第二代 (1990-2010)** | 貝葉斯網路、認知模型、自適應測驗 | Cognitive Tutor, ALEKS, Andes |
| **第三代 (2010-2020)** | 機器學習、深度知識追蹤 (DKT)、強化學習 | Knewton, Squirrel AI |
| **第四代 (2020-現在)** | 大語言模型、生成式 AI、多模態、長上下文 | Khanmigo, MathGPT, 本平台 |

#### 核心演算法對照
| 演算法 | 原理 | 優點 | 缺點 | 適用場景 |
|--------|------|------|------|----------|
| **BKT (Bayesian Knowledge Tracing)** | 隱馬可夫模型 | 解釋性強、數據需求少 | 單一技能、靜態參數 | 早期系統、技能數少 |
| **DKT (Deep Knowledge Tracing)** | LSTM/RNN 序列建模 | 捕捉長期依賴、多技能 | 黑盒、需大量數據 | 大規模平台、技能多 |
| **SAKT (Self-Attention KT)** | Transformer | 並行計算、捕捉長距離 | 參數多 | 高併發、長序列 |
| **GKT (Graph-based KT)** | 圖神經網路 + 知識圖 | 利用先備關係、可解釋 | 複雜度高 | 結構化學科 (數學) |
| **LLM-based KT** | 大模型微調/提示工程 | 零樣本泛化、自然語言互動 | 成本高、幻覺風險 | 新一代對話式導師 |

### 2. 數學教育專用 AI 技術

#### 符號計算與自動推理
| 技術 | 應用 | 成熟度 | 整合方式 |
|------|------|--------|----------|
| **SymPy / Mathematica / Maple** | 符號運算、化簡、解方程 | 成熟 | API 呼叫 / 嵌入式 |
| **自動定理證明 (ATP)** | 幾何證明、邏輯推理 | 專業領域 | 特定模組 |
| **神經符號系統** | 結合神經網路與符號推理 | 研究前沿 | 核心創新點 |

#### 手寫數學識別 (HME)
| 方案 | 準確率 | 延遲 | 部署 | 成本 |
|------|--------|------|------|------|
| **Mathpix API** | 極高 | 低 | 雲端 | 高 |
| **自建模型 (CAN / BTTR / UniMERNet)** | 高 | 中 | 邊緣/雲端 | 中 |
| **LaTeX-OCR (開源)** | 中高 | 低 | 本地 | 免費 |

#### 幾何/圖形理解
- **GeoGebra / Desmos API** - 互動式幾何構造、圖形驗證
- **視覺-語言模型 (GPT-4V, LLaVA, Qwen-VL)** - 圖形描述、問題理解
- **幾何知識圖譜** - 定理鏈、圖形關係結構化

### 3. 教學策略與支架理論

#### 蘇格拉底式教學法 (核心)
```
核心原則:
1. 不直接給答案
2. 透過提問引導學生思考
3. 從學生已知連結到未知
4. 遞減支架
5. 驗證理解後再進階
```

#### 支架類型與遞減
| 層級 | 類型 | 範例 | 適用時機 |
|------|------|------|----------|
| **L1** | 概念釐清 | "分配律是什麼意思？" | 學生完全卡住 |
| **L2** | 引導性問題 | "括號裡有幾項？每一項都要乘到嗎？" | 學生有部分概念 |
| **L3** | 類比/生活例子 | "像發糖果：2袋，每袋1顆巧克力+3顆糖" | 概念抽象難理解 |
| **L4** | 反例/認知衝突 | "如果只乘第一項會發生什麼？" | 學生有錯誤直覺 |
| **L5** | 步驟示範 | "第一步：2×x=2x，第二步：2×3=6" | 多次嘗試仍失敗 |
| **L6** | 直接教學 | "答案是 2x+6" | 最後手段、時間壓力 |

#### 遞減原則
- 學生掌握度 ↑ → 支架層級 ↓
- 同一錯誤重複 3 次 → 升級支架層級
- 連續 2 次正確 → 降級支架層級

### 4. 自適應學習與個人化

#### 學生模型維度
| 維度 | 指標 | 更新頻率 | 用途 |
|------|------|----------|------|
| **知識掌握度** | Mastery Score (0-100) | 每次作答即時 | 內容推薦、難度調整 |
| **錯誤模式** | Error Pattern 分布 | 每次錯誤 | 錯誤診斷、支架選擇 |
| **學習風格** | 視覺/聽覺/動覺/閱讀 | 長期觀察 | 內容呈現方式 |
| **情感狀態** | 挫折度/自信度/投入度 | 即時 (對話/行為) | 干預時機、語氣調整 |
| **認知負荷** | 工作記憶佔用 | 任務中 | 步驟粒度、提示頻率 |
| **元認知能力** | 自我監控/規劃/評估 | 長期 | 學習策略建議 |

#### 內容推薦演算法
| 策略 | 原理 | 適用場景 |
|------|------|----------|
| **Knowledge Tracing + Bandit** | KT 預測掌握度 + UCB 探索利用 | 題目推薦 |
| **Learning Path Optimization** | MDP/RL 最佳化學習路徑 | 課程規劃 |
| **Collaborative Filtering** | 相似學生行為模式 | 資源推薦 |
| **Content-based + KP Matching** | 知識點對齊 + 難度梯度 | 相似題生成 |

### 5. 對話式 AI 教學系統

#### 系統架構
```
User Input
    ↓
[Intent Classification] → [教學/閒聊/作弊/其他]
    ↓
[Context Builder] → Student Profile + Mastery + History + RAG
    ↓
[Pedagogical Policy] → 選擇教學階段/策略/支架
    ↓
[Response Generation] → LLM + 教學約束 + 安全過濾
    ↓
[Output Guardrails] → 格式/安全/教學原則檢查
    ↓
User Output
```

#### 關鍵技術挑戰
| 挑戰 | 現狀 | 解決方向 |
|------|------|----------|
| **長上下文記憶** | Context Window 限制 | 摘要壓縮、向量檢索、結構化記憶 |
| **教學一致性** | LLM 易偏離教學原則 | 系統提示詞工程、RLHF 對齊、輸出約束 |
| **數學推理準確** | LLM 易犯算術/邏輯錯誤 | 符號計算器整合、CoT 強制、驗證器 |
| **幻覺控制** | 編造知識點/解法 | RAG 強制引用、輸出驗證、不確定性表達 |
| **多輪一致性** | 長對話易自相矛盾 | 狀態追蹤、記憶模組、一致性檢查 |

### 6. 評估體系

#### 學生學習成效評估
| 指標 | 定義 | 測量方式 |
|------|------|----------|
| **學習增益** | 前測後測分數差 | 標準化測驗 |
| **掌握速度** | 達到 Mastery 閾值所需時間/題數 | 系統記錄 |
| **迁移能力** | 新情境/新題型解題成功率 | 迁移測驗 |
| **保持率** | 一段時間後重測保持率 | 延遲後測 |
| **自我效能感** | 學生對自己能力的信心 | 問卷量表 |

#### 系統品質評估
| 維度 | 指標 | 目標 |
|------|------|------|
| **教學完成率** | 學生在 AI 引導下完成解題比例 | ≥ 80% |
| **平均引導輪數** | 從提問到完成的對話輪數 | 5-8 輪 |
| **錯誤診斷準確率** | AI 識別學生錯誤類型正確率 | ≥ 85% |
| **支架適當性** | 專家評分支架層級/類型適合度 | ≥ 4.2/5 |
| **學生滿意度** | 對話後評分/繼續使用意願 | ≥ 4.2/5 |
| **安全事故率** | 違規內容/有害建議/洩漏隱私 | 0 |

## 前沿趨勢追蹤 (2024-2025)

| 趨勢 | 關鍵進展 | 對我方影響 |
|------|----------|------------|
| **小模型蒸餾** | Phi-3, Gemma 2, Qwen 2.5 小模型逼近大模型 | 降低部署成本、邊緣部署可能 |
| **長上下文 (128K-1M)** | Gemini 1.5, Claude 3, Qwen 2.5 | 完整學習歷程注入、無需複雜記憶系統 |
| **多模態原生** | GPT-4o, Gemini 1.5, Qwen2-VL | 手寫/語音/圖形無縫互動 |
| **Agentic Workflows** | ReAct, Plan-and-Execute, Multi-agent | 複雜教學任務分解、工具使用 |
| **RAG 進階** | GraphRAG, HyDE, Self-RAG, Corrective RAG | 檢索品質大幅提升 |
| **合成資料生成** | 以大模型生成訓練資料 (SFT/DPO) | 大幅降低資料標註成本 |
| **憲法 AI / 原則對齊** | Claude Constitutional AI, RLAIF | 安全性/教學原則內建模型 |

## 競品分析參考

| 產品 | 定位 | 核心技術 | 優點 | 缺點 | 我方差異化 |
|------|------|----------|------|------|------------|
| **Khanmigo (Khan Academy)** | 全科 AI 導師 | GPT-4 + 提示工程 | 內容豐富、品牌強 | 非本地化、非台灣課綱 | 台灣課綱、本地化、數學深度 |
| **Photomath** | 拍照解題 | CV + 符號引擎 | 解題快、步驟詳 | 僅解題、非教學 | 教學引導 > 解題 |
| **Squirrel AI** | 自適應學習 | 知識圖譜 + DKT | 精細度高 | 互動單一、價格高 | 互動式教學、對話式 |
| **MathGPT / 國內大模型** | 數學專用模型 | 微調 + 符號引擎 | 數學強 | 通用能力弱、部署貴 | 教學體系整合、不只模型 |
| **本地補習班數位化** | 線上課程/題庫 | 影片+題庫 | 內容權威 | 缺乏 AI 個人化 | AI 核心、個人化 |
